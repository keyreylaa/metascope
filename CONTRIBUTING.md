# Contributing to Metascope

Thank you for considering contributing to Metascope! Please read this short guide before submitting a pull request.

## How to Contribute

1. Fork the repository on GitHub.
2. Clone your fork locally.
3. Create a new branch for your feature or fix (`git checkout -b feature/awesome-feature`).
4. Make your changes.
5. Ensure the code passes linting and tests:
   ```bash
   npm run typecheck && npm run lint && npm test
   ```
6. Commit your changes with a clear, descriptive message.
7. Push to your fork and open a pull request against the `main` branch of this repository.

## Code Style

- We use TypeScript with strict mode.
- Formatting is enforced via Prettier and ESLint.
- Please follow the existing style in the project.

## Reporting Issues

If you find a bug or have a feature request, please open an issue on GitHub with as much detail as possible.

Thank you!
